# Архив: бинарная KMeans-кластеризация страхового риска

Скрипт строит два кластера на апреле–мае и проверяет их на июне–августе.
Он не входит в основной проект: пробег оценивается через три произвольных
сценария расхода топлива, покупки вне сервиса не наблюдаются, а страховых
убытков в данных нет. Поэтому результат нельзя считать подтверждённой моделью
страхового риска.

Запуск из корня проекта:

```bash
.venv/bin/python archive_insurance_driver_clustering/run_analysis.py
```
