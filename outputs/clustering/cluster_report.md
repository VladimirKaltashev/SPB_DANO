## Как использовать результат

`client_features_precrisis.csv` содержит рассчитанные признаки и кластер каждого клиента. `client_clusters.csv` — компактное соответствие client_id → cluster_id. Для анализа кризиса эти группы следует соединить с клиентско-недельной панелью июня–августа, не переобучая кластеры.

Кластеры являются описательной сегментацией, а не доказательством причинного влияния кризиса.
