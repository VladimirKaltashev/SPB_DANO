# Кластеризация водителей до топливного кризиса

Пайплайн формирует одну строку на клиента, агрегируя его автомобили, исторические
штрафы и операции на АЗС до 1 июня 2026 года. Данные кризисного периода не входят
в признаки кластеризации.

## Полный запуск

Из папки проекта:

```bash
uv run python main.py
```

`main.py` последовательно:

1. строит докризисные признаки и кластеры;
2. сохраняет `cluster_id` для каждого клиента;
3. сравнивает поведение до и после 1 июня 2026 года;
4. сравнивает штрафы за одинаковые месяцы 2025 и 2026 года;
5. создаёт таблицы, графики и текстовый отчёт.

По умолчанию исходные CSV ищутся сначала в `data/raw/`, затем в
`/Users/vlad/DANO/SPB`. Другую папку можно передать явно:

```bash
uv run python main.py --data-dir /path/to/csv
```

Число кластеров выбирается автоматически среди вариантов от 3 до 8. Для
фиксированного варианта используйте `--clusters 5`. Вручную можно
задать и больше 8 кластеров; графики и таблицы адаптируются к фактическому
числу групп.

Чтобы повторить только анализ по уже сохранённым кластерам:

```bash
uv run python main.py --skip-clustering
```

Отдельный запуск модуля анализа:

```bash
uv run python cluster_analys.py
```

Модуль автоматически принимает столбцы `cluster_id` или `cluster` и определяет
фактическое число групп из файла. Оно не зафиксировано в коде.

## Результаты

После запуска в `outputs/clustering/` появляются:

- `tables/client_features_precrisis.csv` — клиентская витрина и кластер;
- `tables/client_clusters.csv` — соответствие `client_id` и группы;
- `tables/cluster_summary.csv` — числовые профили кластеров;
- `tables/cluster_category_profiles.csv` — демографические профили;
- `tables/cluster_diagnostics.csv` — сравнение числа кластеров;
- `cluster_report.md` — подробное описание результата;
- `figures/` — размеры, тепловая карта профилей и PCA-проекция;
- `models/client_clustering.joblib` — подготовка признаков и модель.

Для интерактивного просмотра используйте `spb_clustering.ipynb`.

После сравнительного анализа в `outputs/cluster_analysis/` появляются:

- `analysis_summary.md` — основные выводы;
- `client_behavior_features.csv` — показатели каждого клиента до и после кризиса;
- `cluster_new_patterns.csv` — статистика изменений по всем кластерам;
- `cluster_fines_2025_vs_2026.csv` — сравнение штрафов год к году;
- `cluster_monthly_trends.csv` — месячная динамика;
- `cluster_pre_post_comparison.png` — сравнение ключевых показателей;
- `cluster_change_heatmap.png` — карта размеров эффектов;
- `cluster_monthly_trends.png` — динамика топлива и штрафов;
- `cluster_fines_2025_vs_2026.png` — сравнение штрафов 2025 и 2026;
- `fuel_price_timeline.png` — динамика цены топлива.
