# Fuel–fines decoupling — Stage 1

Отдельный анализ связи изменений наблюдаемых покупок топлива и числа штрафов
у одного и того же клиента. Предыдущие анализы не изменяются.

```bash
.venv/bin/python fuel_fines_decoupling_analysis/run_analysis.py
.venv/bin/python fuel_fines_decoupling_analysis/test_models.py -v
```

Результат: [отчёт](outputs/diagnostic_summary.md), [HTML](outputs/index.html),
основная таблица `outputs/tables/main_results_table.csv`, ровно три PNG в
`outputs/figures/`, полный аудит источников и выборки в `outputs/metadata.json`.

Основная когорта: подписка не позже 1 апреля 2026, пять месяцев апрель–август,
включая нулевые покупки и штрафы. Очищенные события повторно сверяются с прежней
панелью по каждому клиенту и месяцу; PriceShock сохраняется без изменения.
Пропуски автомобильных характеристик не исключают клиента из основных моделей.

Модели: between на клиентских средних; линейные Client FE + Month FE с литрами/100,
с добавлением PriceShock, и с индикатором покупки; одна conditional Poisson
robustness с клиентскими эффектами и Month FE. Основные ошибки по 16 регионам;
клиентская кластеризация показана отдельно. Параметры поглощённых эффектов учтены
в finite-sample correction OLS. Для Poisson явно показана потеря клиентов без
штрафов за весь период. Воспроизводимые тесты проверяют FE против явных dummies.

PRE апрель–май, POST июнь–август — месячные средние. Процентные изменения только
при PRE > 0; терцили реализованных изменений — исключительно описание, не модель.
Наблюдаемые покупки не равны пробегу; причинного анализа или Stage 2 нет.
