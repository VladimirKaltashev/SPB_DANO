# Расчёты и очищенный датасет

Этот файл — единая точка входа в текущий результат проекта. Он описывает
воспроизводимый контур от `data/raw/` до очищенных таблиц и основной проверки
гипотезы. Сами исходные CSV не изменяются; очищенные версии хранятся в
`data/processed/` через Git LFS.

## Короткий вывод

На фиксированной когорте клиентов, подключённых не позднее 1 апреля 2026 года,
после отсечки 1 июня:

| Метрика | До | После | Изменение |
|---|---:|---:|---:|
| Наблюдаемая цена топлива, ₽/л | 69,27 | 71,19 | **+2,78%** |
| FuelRate, л на клиента за 30 дней | 114,45 | 83,97 | **−30,48 л (−26,63%)** |
| FineRate, штрафов на клиента за 30 дней | 0,5648 | 0,5775 | **+0,0127** |

Изменение FineRate практически эквивалентно нулю при заранее заданной границе
±0,05: 90% ДИ `[0,0013; 0,0240]`, `n = 23 467`, TOST `p < 0,001`.
В пропорциональном сценарии падения топлива уровень FineRate равен 0,4144,
фактический post-уровень — 0,5775; разрыв составляет 0,1631 штрафа на клиента
за 30 дней. Это ассоциация с периодом, а не доказанный причинный эффект роста
цены: покупки через сервис не равны всему пробегу или всему потреблению топлива.

## Что именно считается

Главный расчёт находится в `current_hypothesis/price_fuel_fines_model.py` и
использует недельную панель `client_week_panel.csv`.

1. Берутся клиенты с датой подключения не позднее `2026-04-01` и наблюдениями
   по обе стороны отсечки `2026-06-01`.
2. Используются только полные 7-дневные недели.
3. Для каждого клиента и периода суммируются топливо и штрафы, затем показатели
   нормируются на 30 дней:
   `rate = total / (число недель × 7) × 30`.
4. Сравниваются одни и те же клиенты до/после: односторонний парный тест цены,
   односторонний парный тест FuelRate, TOST для FineRate и тест фактического
   FineRate против пропорционального контрфакта.

Графики и таблицы этого расчёта находятся в
[`outputs/presentation_math_model/`](outputs/presentation_math_model/):

- [`statistics_for_slides.csv`](outputs/presentation_math_model/statistics_for_slides.csv) — основные оценки;
- [`robustness_results.csv`](outputs/presentation_math_model/robustness_results.csv) — спецификации и регионы;
- [`tost_sensitivity.csv`](outputs/presentation_math_model/tost_sensitivity.csv) — чувствительность к margin;
- [`regression_results.csv`](outputs/presentation_math_model/regression_results.csv) — дополнительная ассоциация ΔPrice с ΔFuel и ΔFines;
- [`chart_manifest.md`](outputs/presentation_math_model/chart_manifest.md) — реестр презентационных графиков.

## Robustness

Основная оценка FineRate `+0,0127` (95% ДИ `[-0,0008; 0,0262]`).
Удаление верхнего 1% по топливу и штрафам даёт почти те же оценки: `+0,0139`
и `+0,0114`. Результат чувствителен к границе post-периода: `+0,0677` при
18 мая и `−0,0456` при 15 июня. Региональные оценки неоднородны; сезонная
поправка 2025 (DiD) хранится в полном CSV, но исключена из презентационных
forest plot, поскольку отвечает на другой вопрос.

## Очищенный датасет

Полный каталог и схема находятся в
[`data/processed/README.md`](data/processed/README.md). Ключевые таблицы:

| Файл | Размер | Назначение |
|---|---:|---|
| `clients_clean.csv` | 28 190 строк, 25 675 клиентов | очищенная клиент×автомобильная таблица с аудитом конфликтов |
| `fines_clean.csv` | 72 959 строк | штрафы с приведённой суммой в рубли |
| `fuel_clean.csv` | 379 699 строк | топливные операции и признаки возвратов |
| `client_week_panel.csv` | 590 525 строк | полная клиент×неделя панель, 23 недели |
| `client_auto_conflicts*.csv` | 94 / 47 строк | аудит дублей и разрешённых конфликтов |
| `fuel_refund_matches.csv` | 23 строки | однозначно сопоставленные возвраты |
| `fuel_negative_unresolved.csv` | 1 477 строк | отрицательные операции без безопасного сопоставления |

Период row-level топлива: `2026-03-20` — `2026-09-04`; аналитическое окно
панели: `2026-04-01` — `2026-08-31`. В панель добавлены нулевые недели, поэтому
отсутствие события не превращается в пропуск.

### Правила очистки

- raw CSV читаются с явными разделителями, типами и преобразованием дат/чисел;
- дубли клиент×автомобиль сворачиваются с сохранением аудита; реальный конфликт
  поля не подменяется молча и отмечается `conflict_*`;
- отрицательные топливные операции сопоставляются только с единственным
  положительным кандидатом в пределах 60 минут при допуске цены 0,01 ₽ и объёма
  0,02 л;
- неоднозначные возвраты не удаляются из аудита и не включаются в физический
  объём основного показателя;
- raw-таблицы не перезаписываются; после очистки выполняются sanity checks и
  сравнение 27 базовых колонок панели с контрольным снимком.

Контрольные значения очистки: 1 500 отрицательных операций, 1 432 клиента с
отрицательными операциями, 23 сопоставленных операции, 5 полных отмен,
18 частичных возвратов, 1 477 нерешённых отрицательных операций и 47
повторяющихся пар клиент×автомобиль. Все программные assertions прошли.

## Воспроизводимость

```bash
# полный pipeline от raw до отчётов
uv run python main.py

# только активная поведенческая гипотеза на готовых processed-данных
uv run python -m current_hypothesis.run_analysis --source processed

# презентационные таблицы и графики математической модели
uv run python -m current_hypothesis.presentation_charts

# тесты
uv run python -m pytest -q
```

`archive_*` содержит остановленные исследовательские ветки и не является
источником текущего вывода. Отдельные регрессионные и региональные таблицы в
`data/processed/` относятся к описательному/поддерживающему анализу и не
заменяют основной парный расчёт выше.
