# Ноутбуки

Ноутбуки не содержат отдельной рабочей логики и не нужны для запуска проекта.

- `cleaning.ipynb` вызывает единственную Python-реализацию очистки.
- `behavior_clustering.ipynb` запускает текущую гипотезу и показывает результаты.

Исторические эксперименты находятся в `archive_exploratory_notebooks/`.
