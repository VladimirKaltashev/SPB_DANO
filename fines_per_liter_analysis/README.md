# Штрафы относительно наблюдаемой топливной активности

Текущий основной анализ. Прежняя проверка PriceShock → ShareHighRisk сохранена
в `../archive_monthly_risk_clustering/` и не переоценивается этим запуском.

```bash
.venv/bin/python -m fines_per_liter_analysis.run_analysis
.venv/bin/python -m unittest fines_per_liter_analysis.test_analysis -v
```

Открыть `outputs/index.html` или `outputs/report.md`. Все результаты находятся
в этой папке, старые модули и исходные CSV не изменяются. Зависимости уже есть
в проекте: pandas, numpy, statsmodels, matplotlib. `--tables-only` пропускает
создание отчёта и графиков. `--archive`, `--data-root`, `--output-dir` позволяют
задать расположение входов и выхода. Корневой `.gitignore` исключает `outputs/`
из Git; результаты воспроизводимы командой запуска при наличии исходников и архива.

## Методика

- Основная единица: регион регистрации клиента × календарный месяц.
- Включены все 25 675 клиентов из v2, включая нулевые покупки и пропуски двигателя.
- Основная интенсивность: **1000 × сумма штрафов / сумма физических литров**.
  Литры — proxy наблюдаемой топливной активности, не точный пробег.
- Региональные цены и апрельский baseline точно совпадают с архивом:
  `PriceShock = avg_fuel_price / baseline_price_region - 1`.
- Основные исходы: литры на водителя, штрафы на водителя, штрафы на 1000 л.
  Для каждого — OLS с константой, без весов, с ошибками по 16 региональным группам,
  поправкой малой выборки и t(G−1). β на единицу PriceShock; для +10 п.п. умножить на 0,1.
- Индивидуальные отношения — только robustness: `100 × fines_i / liters_i`,
  пороги 10/20/40 л выбраны по распределению литров до просмотра регрессий.
  Основной порог 20 л; результаты всех порогов сохраняются.
- Сохранённые NO_LITERS метки используются без переобучения. Current-month группы
  содержат штрафы текущего месяца в определении и потому являются описательными.
- Лаговая проверка соединяет группу из t−1 с исходами t строго по календарному месяцу.
  Получается май–август, по 64 ячейки на группу. Отсутствие апреля также меняет выборку.
- Региональные примеры выбраны только по росту цены к августу: минимум, верхняя
  медианная позиция, максимум. Наряду с ними показана динамика всех 16 регионов.

`prepare_data.py` проверяет SHA-256 исходников против архивного запуска,
полноту когорты v2 и совпадение каждого клиент-месяца с детальными очищенными
операциями. Несовместимые источники останавливают расчёт. Архивная таблица
используется до исключения отсутствующих характеристик двигателя. В группах
нет 51 клиента с пропусками двигателя, но они остаются в основном анализе.

## Выходы

- `tables/region_month.csv`: полная региональная панель с числителями и знаменателями.
- `tables/regression_summary.csv`: три основные, шесть текущих групповых и шесть лаговых оценок.
- `tables/main_and_current_risk_results.csv`, `lagged_risk_results.csv`: отдельные блоки.
- `tables/region_month_risk_current.csv`, `region_month_risk_lagged.csv`: групповые панели.
- `tables/liters_distribution.csv`: запрошенные квантили всех и положительных литров.
- `tables/individual_threshold_results.csv`: три индивидуальные проверки.
- `tables/individual_ratios.csv`: индивидуальные отношения и флаги порогов.
- `tables/individual_threshold_cell_coverage.csv`: состав пороговых выборок по ячейкам.
- `tables/selected_regions.csv`, `regional_dynamics.csv`, `national_monthly.csv`: динамика.
- `tables/source_reconciliation.csv`, `price_reconciliation.csv`, `risk_coverage.csv`: сверки.
- `outputs/analysis_plan.json` (относительно корня этого модуля): предварительные правила выбора.
- `outputs/metadata.json`: источники, хеши, версии библиотек и численность выборок.
- `figures/`: три основных scatter plot, динамика всех регионов и выбранных примеров,
  общая динамика и квантили литров. Каждый график в PNG и SVG.

## Интерпретация

Наблюдаемая значимость не устанавливает причинность. Pooled OLS не включает
фиксированные эффекты региона и месяца. Покупки вне сервиса и запас топлива
не наблюдаются; значительная часть штрафов относится к месяцам без покупки
топлива в сервисе. Снижение знаменателя может повышать отношение штрафов к литрам
без изменения поведения. Незначимость не доказывает нулевого эффекта.
Групповые и пороговые p-value номинальные, без поправки на множественные проверки.
Кластеризацию следует рассматривать как приложение к основному анализу.

Текстовый отчёт не принуждает результат к A–D, если наблюдаемая комбинация
знаков и значимости не соответствует ни одной из заранее предложенных категорий.
