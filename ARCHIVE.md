# Архив исследовательских гипотез

Папки `archive_*` не участвуют в запуске `main.py`. Код, тесты и локальные
результаты сохранены для воспроизводимости, но эти ветки не следует путать с
активным поведенческим анализом.

| Папка | Проверявшаяся идея | Почему не в основном контуре |
|---|---|---|
| `archive_monthly_risk_clustering/` | рост цены снижает долю месячного high-risk кластера | отрицательный коэффициент статистически незначим; кластеры нестабильны между месяцами |
| `archive_fines_per_liter_analysis/` | рост цены снижает интенсивность штрафов на наблюдаемые литры | интенсивность, наоборот, выросла; литры сервиса не равны пробегу |
| `archive_usage_composition_analysis/` | изменение состава покупателей объясняет результат | совместная поддержка механизма не получена |
| `archive_fuel_fines_decoupling_analysis/` | покупки топлива и штрафы полностью расходятся внутри клиента | осталась положительная, хотя слабая, within-связь |
| `archive_vehicle_sensitivity_analysis/` | большие двигатели слабее сокращают объём топлива | широкая формулировка не подтверждена; отдельный сигнал относится только к вероятности покупки |
| `archive_insurance_driver_clustering/` | KMeans по условному пробегу выделяет страховой риск | пробег восстановлен из сценарного расхода, страховых убытков нет, модель не входит в основной дизайн |
| `archive_exploratory_notebooks/` | ранние notebook-проверки цены, штрафов и очистки | дублируют последующие воспроизводимые скрипты либо являются локальными черновиками |

Архивы можно запускать отдельно командами из их `README.md`. Они могут читать
результаты более ранних архивных этапов, но не импортируются активным кодом.
