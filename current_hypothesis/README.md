# Текущая гипотеза

## Формулировка

**H1:** после роста цены топлива с 1 июня 2026 года поведение водителей
изменилось по-разному в заранее определённых поведенческих группах.

**H0:** изменения после 1 июня не различаются между группами сверх случайных
колебаний.

Группы строятся только по информации, доступной до 1 июня. После этого для
тех же клиентов сравниваются показатели топлива и штрафов до/после отсечки.

## Где находится проверка

- `check_hypothesis.py` — непосредственный расчёт изменений и статистических
  тестов. Основная функция: `summarize_cluster_changes()`.
- `define_groups.py` — только назначение докризисных групп; саму гипотезу этот
  файл не проверяет.
- `prepare_clients.py` — подготовка клиентских признаков.
- корневой `main.py` — единая команда, которая последовательно вызывает все
  три этапа.

Результат проверки записывается в:

- `outputs/behavior_cluster_analysis/cluster_new_patterns.csv`;
- `outputs/behavior_cluster_analysis/analysis_summary.md`;
- `outputs/behavior_cluster_analysis/index.html`.

Запуск из корня проекта:

```bash
uv run python main.py --source processed
```

## Что проверено сейчас

Текущая реализация делает парные сравнения одних и тех же клиентов до и после
отсечки отдельно в каждой группе. Изменение отмечается как заметное, если есть
не менее 40 наблюдений, `q <= 0.05` после поправки Benjamini–Hochberg и размер
эффекта не меньше 0.20 по модулю.

Это **частичная**, а не окончательная проверка H1. Она показывает, какие группы
изменились, но пока не содержит единого теста взаимодействия
`группа × период`, необходимого для строгого вывода, что группы отреагировали
именно по-разному. Анализ также не доказывает причинное влияние цены.
